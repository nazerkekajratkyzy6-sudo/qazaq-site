# ҚАЗАҚ — ҰЛТТЫ ОЯТҚАН ГАЗЕТ

React + TypeScript + Vite + Tailwind CSS. База данных не нужна; прогресс хранится в localStorage. Маршрутизация — HashRouter (прямые ссылки и QR работают на любом статическом хостинге).

## Запуск
```
npm install
npm run dev        # разработка
npm run build      # сборка в dist/
npm run preview
```

## Деплой на Vercel
1. Загрузите папку в GitHub-репозиторий (без `node_modules`, `dist`).
2. Vercel → Add New Project → выберите репозиторий. Framework: Vite (определится автоматически), Build: `npm run build`, Output: `dist`.
3. После публикации откройте на сайте кнопку ⧉ «QR және сілтемелер», вставьте адрес сайта — появятся QR и прямые ссылки. До публикации адреса не подставляются.
   Либо: `SITE_URL=https://ваш-сайт.vercel.app npm run qr` — PNG в `public/qr/`.
   Можно задать `VITE_SITE_URL` в настройках Vercel.

## Структура
- `src/data/` — все материалы: `documents.ts` (архивные страницы), `timeline.ts`, `figures.ts`, `topics.ts`, `sources.ts`, `glossary.ts`.
- `src/pages/`, `src/components/`, `src/games/`, `src/lib/`.
- `public/img/` — изображения (кадрированы из исходников, чёрные поля и интерфейс телефона убраны, содержимое не изменено).

## Как добавить
- **Страницу газеты:** положите JPG в `public/img/`, добавьте объект в `DOCS` (`documents.ts`). Поля `issue`, `date`, `author` заполняйте только если установлены; `transcription` — только проверенный текст (иначе вкладка честно покажет, что текста нет). Аннотации — прямоугольники в процентах.
- **Источник:** объект в `SOURCES`, затем его `id` в `sourceIds` нужных материалов.
- **Событие:** `EVENTS` (`status`: verified / context / disputed).
- **Публикацию в таблицу результатов:** массив `ROWS` в `src/pages/Results.tsx`.

## Что нужно проверить перед защитой
Список недостающих материалов — на странице «Нәтиже». Главное: открыть №42 (1913), №91 (1914) и статьи 1914–1918 в оригинале; уточнить авторство и права на изображения; дату последнего номера (источники расходятся: январь / 26 сентября 1918).
